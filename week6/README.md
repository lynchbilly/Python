# Week 6: File I/O

This week covers file input/output in Python:
- Reading files
- Writing files
- CSV files
- PIL (Python Imaging Library)

## Exercises

- `lines.py` - Count lines of code in a Python file
- `pizza.py` - Format pizza menu from CSV
- `scourgify.py` - Reorganize student data from CSV
- `shirt.py` - Add shirt overlay to photos using PIL
