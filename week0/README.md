# Week 0: Functions, Variables

This week covers the fundamentals of Python programming:
- Functions
- Variables
- Data types
- Input/Output

## Exercises

- `hello.py` - Simple hello world program
- `indoor.py` - Convert text to lowercase
- `playback.py` - Replace spaces with ellipses
- `faces.py` - Convert emoticons to emoji
- `einstein.py` - Calculate energy using E=mc²
- `tip.py` - Calculate tip amount
