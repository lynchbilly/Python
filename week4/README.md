# Week 4: Libraries

This week covers Python libraries and modules:
- Importing modules
- Standard library
- Third-party libraries
- random, statistics, sys, requests modules

## Exercises

- `emojize.py` - Convert text codes to emoji using emoji library
- `figlet.py` - ASCII art text using pyfiglet
- `adieu.py` - Bidding adieu with inflect library
- `game.py` - Guessing game using random
- `bitcoin.py` - Bitcoin price checker using requests
- `professor.py` - Math quiz generator
